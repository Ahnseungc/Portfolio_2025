# Portfolio 2026

안승찬 포트폴리오 — 이력서(2026) 및 `web/` 라이트 테마 포트폴리오와 동기화된 데이터를 `src/data/index.ts`에 반영했습니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 데이터

- **경력**: (주)골드앤컴퍼니, (주)케어마인더, (주)리케어랩
- **프로젝트**: 금 모으기 앱테크, 금 매입, QR 병상 오더, 병동 요청 플랫폼, 케어나인 홈, TemMoa(해커톤)
- **수상·스킬**: 이력서 기준으로 정리
